# MeshDock

给 Tailscale / 自建 Headscale 组网用的 Windows 中文图形客户端：一眼看懂每台设备连上了没有、走的是哪条路、快不快，常用操作做成按钮。

本工具**不修改、不替换官方客户端**，只调用官方命令行 `tailscale.exe`，读取结果后用中文展示。

## 下载

到 [Releases](https://github.com/chengzhirenchaoshuai/MeshDock/releases/latest) 下载最新版。两种版本任选其一，**推荐安装版**（可以一键自动更新）：

- **安装版** `MeshDock_<版本>_x64-setup.exe`：装到当前用户，不需要管理员权限。电脑上没有 WebView2 时，安装程序会自动下载安装。卸载在“设置 → 应用”里找 MeshDock。
- **免安装版** `MeshDock_<版本>_x64-portable.exe`：单个文件，直接运行。数据和安装版一样放在用户文件夹下（设置在 `%APPDATA%\com.meshdock.app`，界面缓存在 `%LOCALAPPDATA%\com.meshdock.app`）。需要电脑上已有 WebView2（Windows 10 一般自带）。
  - 想让数据跟着程序走（例如放在 U 盘里），在 exe 旁新建一个 `data` 文件夹即可，设置和界面缓存都会改存到里面。

## 第一次使用

1. **先装好官方客户端并登录**：MeshDock 只是官方客户端的“中文仪表盘”，组网本身仍由官方客户端负责。到 [tailscale.com/download](https://tailscale.com/download/windows) 安装 Windows 版并登录你的组网（用 Headscale 的，按控制端管理员给的方法登录，例如 `tailscale up --login-server=https://你的控制端地址`）。官方客户端默认装在 `C:\Program Files\Tailscale\tailscale.exe`；装在别处时可用环境变量 `MESHDOCK_TAILSCALE` 指定。
2. **运行 MeshDock**：程序没有购买代码签名证书，第一次运行时 Windows 可能提示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”即可。之后它会常驻在任务栏右下角的托盘里。
3. **按需设置**（都在“设置”页，不设也能用）：
   - **自建中继 → 显示名称**：组网用自建中继（DERP）时，可以填中继服务器所在的城市，设备走中继时显示为“中继（经 这个名称）”。
   - **在家识别**：只有组网里有子网路由器（用来在外面访问家里局域网）时才需要。在家时点一下“当前默认网关”，之后 MeshDock 会自动判断你在不在家，提醒或自动切换在家 / 出门模式。
   - **快捷连接**（可选）：在 `~/.ssh/config` 里给设备写好别名，设备卡片上就会出现“SSH”按钮；装了 RustDesk 会出现“RustDesk”按钮，一键直连对方。
4. **更新**：有新版本时设置标签上会出现小圆点并发通知。到“设置 → 关于”点“立即更新”，会自动下载、校验签名、安装并重新打开。免安装版会直接替换当前的程序文件（文件名不变）；如果程序放在不能写入的文件夹（如 `C:\Program Files`），或者旧版本没有提供免安装版更新，就点“打开下载页”，下载新的 portable.exe 替换旧的即可，设置不会丢。

## 功能

- **设备列表**：每台设备的在线状态、连接方式（局域网直连 / IPv6 直连 / 公网直连 / 中继 / 正在打洞 / 在线·空闲 / 离线）、走中继时的可能原因、收发流量、最后在线时间；点击 IP 复制。默认每 10 秒自动刷新（可在设置中改为 5～60 秒）。
- **测速与延迟历史**：单台“测试”或“全部测试”；后台默认每 5 分钟自动测一次（可在设置中改为 1～10 分钟），卡片上显示 24 小时延迟小图；点小图看 24 小时 / 7 天详情和统计，可导出 CSV。可设置延迟持续偏高、长时间走中继时提醒。
- **快捷连接**：按 `~/.ssh/config` 的别名一键 SSH；用组网 IP 一键 RustDesk 直连。
- **网络体检**：检查 UDP、IPv6、NAT 类型、到自建中继的延迟，翻译成人话；可导出诊断报告（公网 IP 自动打码），方便发给运维。
- **在家 / 出门模式**（组网里有子网路由器时）：显示并切换 accept-routes；按默认网关自动识别在不在家，模式开错时醒目提示并可一键改回；可选开启“自动切换”，回家或出门时自动改过来。
- **子网路由器**：显示组网里子网路由器的健康状态（在线、IPv6、NAT 类型、到中继的延迟）。
- **出口节点**：选用组网里的某台设备当出口上网，可开关“走出口时访问本地局域网”；出口设备离线时醒目提示并发通知。
- **发文件**：设备卡片上一键选文件，或直接把文件拖到设备卡片上，用 Taildrop 发给对方。
- **共享本机服务**：把本机的网页或 TCP 端口共享给组网里的其他设备（只在组网内可见）。
- **设备搜索、备注和收藏**：按名称、备注、IP、系统搜索设备，可只看在线的；可给设备写备注、收藏常用设备（排在最前，只存本机）。
- **组网选项与账户**：设置页可开关“允许其他设备连接本机”、“使用组网 DNS”、“无人登录时保持连接”，并在多个已登录账户之间切换。
- **官方客户端启动方式**：开关官方托盘的开机自启；能 SSH 的 Windows 设备也可远程开关无人值守和托盘自启。
- **新版本提醒与自动更新**：官方客户端有新版本时在本机卡片上注明并发通知；MeshDock 自身有新版本时也提醒，在“设置 → 关于”点“立即更新”即可自动下载、校验签名、安装并重新打开（安装版和免安装版都支持）。
- **连接 / 断开组网**：断开前二次确认；重新连接时不会改动现有设置。
- **通知**：设备在直连和中继之间变化、模式开错时发 Windows 通知。
- **托盘**：圆点颜色表示整体状态（绿=已连接、灰=未连接、红=控制端连不上），右键中文菜单，可直接切换出口节点、打开某台设备的 SSH。
- **设置**：外观（跟随系统 / 浅色 / 深色）、检测周期（状态刷新、后台测速）、家里路由器地址、自建中继显示名、通知、开机自启、关闭窗口时最小化到托盘。

## 使用提示

- Windows 10 会把新出现的托盘图标收进任务栏右侧的“^”里。把 MeshDock 图标拖到任务栏上，就能一直看到状态圆点。
- 默认关闭主窗口只是隐藏到托盘，要退出请在托盘图标上右键选“退出”；如果希望关闭窗口就退出程序，在“设置 → 启动与关闭”中取消“关闭窗口时最小化到系统托盘”。
- 本机设置保存在 `%APPDATA%\com.meshdock.app\settings.json`（便携模式在 `data\settings.json`），只有界面偏好、备注和收藏，不保存任何密钥。
- 遇到问题时，到“网络体检”页导出诊断报告（公网 IP 已自动打码），发给帮你维护组网的人。

## 隐私

MeshDock 只在本机调用 `tailscale.exe`，不收集、不上传任何数据。唯一主动联网的是检查新版本：读取本仓库 GitHub 发布里的 `latest.json`。

## 开发

环境：Rust 1.98+、Node 24+、pnpm 12+，Windows 10 22H2 及以上。

```powershell
pnpm install          # 安装前端依赖
pnpm tauri dev        # 开发模式运行（与正式版共用数据，正式版在运行时只会唤出它的窗口）
pnpm dev:test         # 开发模式，用测试标识 com.meshdock.test 运行：数据单独存放，可与正式版同时运行
pnpm test             # 前端单元测试（后端测试在 src-tauri 下执行 cargo test）
pnpm package          # 打包：安装版、免安装版和自动更新用的 latest.json 输出到项目根目录 release\
```

### 发布新版本

自动更新靠签名防止安装包被替换：打包时用私钥签名，程序里只有公钥（`src-tauri/tauri.conf.json` 的 `plugins.updater.pubkey`）。

1. 私钥放在与项目文件夹同级的 `ProjectKey\MeshDock\meshdock.key`（不在仓库里），也可以用环境变量 `TAURI_SIGNING_PRIVATE_KEY` 指定。**务必另外备份**，丢了以后已安装的旧版本就收不到自动更新了。
2. 改 `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 中的版本号，在 `CHANGELOG.md` 写好这一版的更新内容（打包时取这一节作为更新说明）。
3. 执行 `pnpm package`，然后发布：

```powershell
gh release create v<版本> --title "MeshDock <版本>" --notes-file <更新说明文件> `
  release\MeshDock_<版本>_x64-setup.exe release\MeshDock_<版本>_x64-portable.exe release\<版本>\latest.json
```

程序读取的是 `releases/latest/download/latest.json`，所以这个发布必须是“最新正式版”（不要勾选预发布），并且要带上 `latest.json`。

技术栈：Tauri 2 + Vue 3 + TypeScript + Tailwind CSS 4。
